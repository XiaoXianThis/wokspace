# agent

Agent material that is not tied to any one agent tool. Every agent may read and use it.

| path | purpose |
|---|---|
| `rules/` | detailed rules by topic, extending `AGENTS.md` |
| `skills/` | reusable procedures |
| `configs/` | shared standard versions of agent configs |
| `memory.md` | lessons learned |

## Rules

- No tool-specific directory layouts here (such as `.kiro/` or `.cursor/`). Tool-specific configs go to `configs/<tool>/` as standard versions that each person copies locally.
- No secrets.
