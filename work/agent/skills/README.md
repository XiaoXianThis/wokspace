# skills

Reusable procedures, such as "release a new version of an app" or "add an API between two apps".

## Rules

- One procedure per file: `<name>.md`. When it needs templates or scripts, use a directory `<name>/` with `<name>/README.md` as the entry point.
- Each skill states its purpose, when to use it, prerequisites, steps, and how to tell it is done.
- Write a skill only after the procedure has been done by hand at least twice. Tell the user when you add one.
- When a step turns out to be outdated while you use a skill, fix it.
